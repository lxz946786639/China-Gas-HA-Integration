# 中国燃气 Node-RED 参考信息（脱敏版）

> 本文件用于记录接口流程和字段含义。为便于上传公开仓库，所有账号、token、用户 ID、手机号、地址、表号、余额、读数、账单金额等真实数据均已脱敏。

## 1. Node-RED 流程摘要

原始 Node-RED 流程包含以下节点：

1. 初始化节点：写入请求所需配置。
2. 中燃注册/埋点接口。
3. Token 检查接口。
4. 生成时间戳。
5. 生成 MD5 签名。
6. 查询账号基本信息。
7. 查询月度账单信息。
8. 从返回值中提取余额和账单数据。

定时查询周期：

```text
21600 秒
```

即 6 小时。

## 2. 初始化节点配置项

Node-RED 初始化节点中的必要信息如下：

```javascript
let initData = {
  // MD5 加密盐，来自小程序 JS
  "secretKey": "<SIGNATURE_SALT>",

  // 燃气编号
  "custCode": "<CUST_CODE>",

  // 用户名，按小程序返回值填写
  "custName": "<CUST_NAME>",

  // 用户 ID
  "userId": "<USER_ID>",

  // 小程序 token
  "accessToken": "<ACCESS_TOKEN>",

  // 来源标识
  "accessFrom": "yphpaymp",

  // 小程序环境信息
  "x-mas-app-info": "<X_MAS_APP_INFO>",

  // 小程序 Referer
  "Referer": "https://servicewechat.com/<WECHAT_APP_ID>/<APP_VERSION>/page-frame.html",
};
```

埋点请求体：

```text
appUseType=0&clickType=3&eventType=1&channelType=0&userId=<USER_ID>
```

## 3. 签名逻辑

签名生成逻辑：

```javascript
const timeStamp = Date.now();
const rawString = custCode + secretKey + timeStamp;
const signature = md5(rawString);
```

请求参数：

```javascript
msg.payload = {
  custCode: "<CUST_CODE>",
  custName: "<CUST_NAME>",
  timeStamp: "<TIMESTAMP>",
  signature: "<SIGNATURE>",
};
```

月度账单接口额外包含：

```javascript
msg.payload = {
  custCode: "<CUST_CODE>",
  custName: "<CUST_NAME>",
  startTime: "<YYYYMM>",
  endTime: "<YYYYMM>",
  timeStamp: "<TIMESTAMP>",
  signature: "<SIGNATURE>",
};
```

```javascript
"Content-Type": "application/json"
```

## 6. 关键返回字段

账号基本信息字段：

| 字段 | 含义 |
| --- | --- |
| `countMoney` | 当前余额 |
| `newCountMoney` | 新余额字段 |
| `oweMoney` / `newOweMoney` | 欠费金额 |
| `qtyBalance` | 剩余气量 |
| `lastRecord` | 最近表底数 |
| `lastRecordTime` | 最近抄表日期 |
| `compName` | 燃气公司 |
| `address` | 地址 |
| `mobile` | 手机号 |
| `meterNo` | 表号 |
| `meterFormName` | 表具型号 |

月度账单字段：

| 字段 | 含义 |
| --- | --- |
| `recordMonth` | 账单月份 |
| `timeLastRecord` | 上次抄表日期 |
| `lastRecord` | 上次读数 |
| `timeCurRecord` | 本次抄表日期 |
| `curRecord` | 本次读数 |
| `curQty` | 本期用气量 |
| `totalFee` | 总费用 |
| `gasFee` | 气费 |
| `laterFee` | 滞纳金 |
| `isPay` | 支付状态 |
